# DoneAt link and hreflang investigation — 2026-11-01

Scope: international production `https://doneat.app`, repository main
`e7f4ea3fb6c0ea4ecae1756d254fb605f3ecea37`, and both regional build variants.
Initially Ahrefs required sign-in. After the user signed in on 2026-11-01, the
2026-10-30 historical report was accessed and all 114 broken-link source rows and

sets and target statuses confirm the independent current-state crawl below.

## Confirmed shared failure

The production sitemap contains 114 canonical pages (19 languages × six pages).
An independent GET crawl returned 200 for every page. All 114 pages contain an
anchor to `https://doneat.app/cdn-cgi/l/email-protection#…`. Removing the fragment
reveals **one shared HTTP target**, which returns **404**. Example source:
`https://doneat.app/en`; example emitted href:
`/cdn-cgi/l/email-protection#5e363b3232311e3a31303b3f2a703f2e2e`.
The source footer instead emits `mailto:hello@doneat.app`. The same rewriting also
occurs in support Markdown. This is Cloudflare Email Address Obfuscation, not an
Astro missing-page route. Ahrefs' historical report lists this exact 404 target,
114 incoming links and first-found source /ar. All 114 historical source URLs
match the independently crawled sitemap page set exactly.

The repeatable HTTP checker fetched 114 sitemap pages and 120 unique same-origin
targets in total. Its only failing HTTP target was the email-protection 404; the
root returned the expected 302 to /en for Accept-Language: en. The four linked
license text files also returned 200.

The evidence file lists every independently observed referring page and status.
The shared footer is present in every language on home, download, privacy, about,
FAQ and how-it-works pages. There are not 114 different broken destinations.

Fix: BaseLayout emits Cloudflare's documented `email_off` comments around slot
content. This protects public support mailto anchors in shared components and
Markdown without changing Cloudflare configuration or inventing a `/cdn-cgi`
route. Literal comments survive Astro output; the generated-link check verifies
that every mailto anchor is inside those boundaries. Existing mailto functionality
and no-JavaScript access are retained. Public support addresses remain public.

Reference: https://developers.cloudflare.com/waf/tools/scrape-shield/email-address-obfuscation/

## Hreflang

Each of the 19 home pages advertises x-default `https://doneat.app/`; support pages
advertise their English page as x-default. Production root with
`Accept-Language: ja` returned 302 `Location: /ja?seo-audit=1` and
`Vary: Accept-Language` when requested with `?seo-audit=1`. Locale pages themselves
return 200. The root is intentionally the language negotiation entry point,
explicitly required by existing SEO policy, so the 19 redirect warnings are
consistent with this design. Authenticated historical details now confirm that
all 19 affected links are x-default to the root (302), finally /en (200), found in
both sitemap and HTML source. No failed locale alternate was present in those
19 rows. Keep the root x-default and language middleware.

Offline validation checks all 2,280 global HTML alternates for existing canonical
pages and reciprocal links, with only hall root x-default exempted from a static
canonical target. Sitemap alternates must match HTML. Mainland builds retain their
own six-page, zh-CN-only graph and origin; do not point international language
alternates to unavailable mainland routes. `off.rainif.com` remains the external
product timer, not a replacement canonical domain.
