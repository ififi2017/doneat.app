# SEO intent backlog

Do not ship these as indexed pages in this round. Write only after a SERP pass for the target locale (`target_market=en-US` unless product says otherwise). Chinese URLs stay high quality; they are not the default growth bet.

## Rule

1. Search the query in the target locale (incognito, relevant region).
2. Note intent (timer utility vs blog vs app store vs “how to count overtime”).
3. If Google already answers it with a calculator, store listing, or thin listicle, either skip or write a page that is clearly more useful than those results — not a synonym-stuffed clone of `/en`.
4. Draft against the live SERP. Do not generate 19 translations of an English outline.
5. Any placeholder route must stay `noindex` until the draft passes review. Prefer keeping candidates in this file over empty URLs.
