## DoneAt が保存するデータ

入力した情報はデフォルトでローカルに保存されます：ウェブタイマーではブラウザのローカルストレージ、iPhone、iPad、Android、Mac、Windows ではアプリのデータフォルダに保存されます。DoneAt は製品アカウントを提供しておらず、この情報を DoneAt のサーバーに送信しません。

iPhone と iPad では、iCloud 同期を有効にすることができます。有効にすると、スケジュール、記録、給与、リマインダー設定、外観、言語、ライフプロフィール、集中データが Apple アカウントに関連付けられたプライベート iCloud データベースに保存されます。通知許可、生体認証保護、ライブアクティビティ設定、現在の作業タイマー、オンボーディング状態は各端末に残ります。ウェブタイマー、Android、Mac アプリ、Windows アプリはローカル保存のままで、この同期には参加しません。

カウントダウン、進捗、収入の見積もりは、この情報を基に端末上で計算されます。

通常、以下が含まれます：

- 出勤・退勤時間、勤務日、休憩または残業の設定
- 給与額、給与期間、キャリア給与履歴
- 勤務記録と修正、キャリアステージ、入力した人生のマイルストーンや日付
- 集中タスクのタイトル、計画、セッション、休憩設定
- 通知とリマインダーの設定
- 言語と外観

## オプションの iCloud 同期

同期はデフォルトでオフです。iPhone または iPad で有効にすると、Apple の CloudKit サービスが上記のデータを Apple アカウントに関連付けられたプライベートデータベースに保存します。DoneAt は自社サーバーにコピーを受け取りません。同じ Apple アカウントを使う端末はそのデータを復元・同期できます。利用可能な iCloud アカウントとネットワーク接続が必要です。

同期を有効にするには DoneAt Plus が必要です。有効化済みの同期はサブスクリプション終了後も継続します。同期をオフにすると、その端末での同期が停止し、現在のローカルコピーと既存の iCloud コピーの両方が保持されます。オフにしてもどちらのコピーも削除されません。

## Android

Android アプリはテスト中です。一般公開と Plus 購入は Google Play でのリリースに従います。勤務データと設定は標準でアプリの専用領域に保存され、DoneAt アカウントやアプリ内の利用状況分析はありません。

システムのバックアップや端末移行には、記録、給与、職歴、人生プロフィール、Focus データ、未完了の初期設定が含まれる場合があります。動作は端末、アカウント、システム設定に依存し、DoneAt のサーバーにはコピーされません。実行中のタイマー、通知予約の管理情報、購入証明は対象外です。復元後は通知を再設定し、購入を再確認します。Google Drive や iPhone との自動同期はありません。手動エクスポートは給与を含み得る読み取り可能な JSON で、選んだ保存先や受信者に独立したコピーが作られます。

購入と任意のレビューは Google Play が処理します。DoneAt はカード情報やレビュー送信の有無を受け取りません。商品 ID とトークンを含む購入証明は、システムバックアップの対象外として端末に保存します。起動、前面への復帰、購入の復元、購入確認の再試行時に照会する場合があります。サーバー検証を有効にした版では、トークン、商品 ID、ランダムなリクエスト識別子を HTTPS で Cloudflare 上の `api.doneat.app` に送信します。Google は Cloud Pub/Sub で変更を通知します。サービスは Google に状態と正確な有効期限を照会し、署名付き証明を返します。勤務データやバックアップは受け取りません。

データベースにはトークンのハッシュ、商品、利用権の状態と期限、確認時刻、テスト購入フラグ、置換先トークンのハッシュ、更新番号を保存し、確認、復元、置換済み購入の再利用防止に使います。通知 ID は30日間の窓で重複排除し、古いものは後続通知の処理時に削除します。元のトークンと Google の応答は一時的に処理するだけで、データベースやアプリケーションログには残しません。IP による一時的な回数制限を行いますが、IP やそのハッシュは DoneAt のデータベースに保存しません。Google と Cloudflare は各自のポリシーに基づき通信を処理します。購入識別子を広告や利用行動の分析には使いません。

リマインダーは端末内で予約します。端末認証では結果のみを受け取り、生体情報や PIN は取得しません。Backdrop（AndroidLiquidGlass）と Shapes の描画はローカルで完結し、内容や識別子を作者へ送信しません。出典とライセンスは[概要](/ja/about#android)にあります。

ローカルデータはアプリ内、アプリのストレージ消去、アンインストールで削除できます。エクスポートとシステムバックアップは保存先で別途削除してください。サーバーの購入記録の削除は [hello@doneat.app](mailto:hello@doneat.app) へ連絡できます。ローカルデータの削除ではサーバー記録は自動削除されず、購読も解約されません。購読は Google Play で管理してください。有効な Plus がなくてもエクスポートと削除は利用できます。


## バックアップのエクスポート

iPhone と iPad では、「エクスポート」を選択したときのみバックアップが作成されます。フルバックアップには記録、同期設定、給与とキャリア給与履歴、ライフプロフィール、集中タスクとセッションが含まれます。ライフプロフィールを除くエクスポートも選択できますが、その場合も給与とキャリア履歴は含まれます。システムの共有シートで保存先や共有先を選べます。

エクスポートは読み取り可能な JSON ファイルであり、パスワード保護されたアーカイブではありません。含まれる情報に適した保存場所と受信者を選んでください。保存または共有したファイルは別のコピーであり、DoneAt でデータを削除してもそれらのファイルは削除されません。

## Plus の購入

iPhone と iPad では、Apple が App Store を通じて Plus サブスクリプションと買い切り購入を処理します。DoneAt は StoreKit を使って購入状態を確認し、アクセスを復元し、確認済みの権利と有効期限のローカル記録を保持します。DoneAt は支払いカードの詳細を受け取らず、購入状態を DoneAt アカウントサーバーに送信しません。Apple は独自のポリシーに基づいて購入情報を処理します。

サブスクリプションが終了しても既存の記録は削除されません。エクスポートと削除には有効なサブスクリプションは不要です。

## 公式サイト

[doneat.app](https://doneat.app) は静的ウェブサイトです。シフトや給与は収集しません。サイトルートや `/privacy` や `/download` などの短いパスを開くと、ブラウザの言語に従ってそのホールまたは英語・簡体字中国語のサポートページに移動します。言語はページ URL に保持され、このサイトは言語 Cookie を設定しません。

ページをホストするため、Vercel は独自のプライバシーポリシーに基づいて IP アドレスやブラウザ識別子などの通常の接続情報を処理する場合があります。このプロジェクトはその情報を保存したり、あなたのプロファイルを作成するために使用したりしません。

公式サイトは Vercel の Cookie レス分析を使用してページビューと読み込みパフォーマンスを測定し、少数の集計カウンターで利用状況を把握しています。イベントは固定の公開リストから来ます。たとえば `hall_view`、`download_view`、`download_from_web`、`web_timer_open`、`app_store_open` など。日ごとにインクリメントされます。リクエストにはイベント名のみが含まれます。ユーザー識別子、セッション、言語、スケジュール、給与は含まれず、個人を特定または追跡するために使用できません。

イベントの完全なリストはこのリポジトリの [`src/lib/analytics-events.ts`](https://github.com/ififi2017/doneat.app/blob/main/src/lib/analytics-events.ts) にあります。

## ウェブタイマーの分析

[off.rainif.com](https://off.rainif.com) のウェブタイマーも Vercel の Cookie レス分析を使用してページビューと読み込みパフォーマンスを測定します。別の限られた集計カウンターセットを使用して全体的な機能使用状況を把握しています。

製品イベントは別の固定公開リストから来ます。たとえば `share_open` や `countdown_start` など。日ごとに集計されます。ユーザー識別子、セッション情報、スケジュール、給与データは含まれず、個人を特定または追跡するために使用できません。

製品イベントの完全なリストは製品のオープンソースリポジトリにあります。ホスティングと分析プロバイダーは各社のプライバシーポリシーに基づいて標準的な接続情報を処理する場合があります。このプロジェクトはその情報を別途保存したり、ユーザープロファイルを作成するために使用したりしません。

## Cookie

ウェブタイマーは `i18nextLng` という Cookie を使用して言語コードを保存し、後の訪問で選択した言語で開けるようにしています。初回訪問時に現在表示されている言語から設定され、言語を変更すると更新され、1 年後に期限切れになり、ブラウザで削除できます。

公式サイトとウェブタイマーは広告やクロスサイトトラッキング Cookie を使用しません。上記の分析は Cookie に依存しません。

## カウントダウンの共有

シェアリンクの URL には出勤・退勤時間のみが含まれます。給与情報は含まれません。リンクを開いた人はシフト時間だけを見ることができます。カウントダウンの共有画像も給与を含みません。バックアップのエクスポートは異なり、給与や上記の他の個人データが含まれる場合があります。

サードパーティのソーシャルサービスを通じて共有する場合は、そのサービスのプライバシーポリシーが適用されます。

## スマートフォンとパソコンのアプリ

iPhone、iPad、Mac、Windows のアプリは使用分析を収集しません。

GitHub からインストールしたデスクトップ版は起動時に新しいリリースがあるか確認します。リクエストにはアカウント、給与、使用状況のデータは含まれず、インストーラーはあなたが更新を確認した後にのみダウンロードされます。GitHub に直接接続できない場合は、サードパーティのミラーを通じてリトライすることもできます。どちらのチャネルからダウンロードしても、インストール前に署名が確認されます。

Microsoft Store からインストールした版は更新チェックを行いません。更新は Microsoft Store が提供します。

リマインダーは OS がローカルでスケジュール・表示します。アプリは外部リンクを開いたり、サードパーティのサービスを通じて共有したりするときにもネットワークにアクセスします。

## ウィジェット、ライブアクティビティ、端末の保護

ウィジェットとライブアクティビティは、タイマーと進捗を表示するために必要な情報を使用します（該当する場合は集中情報も含む）。給与は含まれません。ローカル通知も給与を含みません。これらの画面はホーム画面やロック画面に表示される場合があります。アプリとシステム設定で可視性と通知許可を管理できます。

DoneAt が収入や記録を保護するために認証を求める場合、認証は端末が Face ID、Touch ID、またはパスコードを通じて処理します。DoneAt は認証結果を受け取りますが、生体データやパスコードは受け取りません。この保護は各端末で個別に設定されます。

## サードパーティサービス

DoneAt は以下のサービスを使用して、ページのホスティング、公式サイトとウェブタイマーの測定、アプリの配布、選択したリンクを開きます：

- Vercel — 公式サイトとウェブタイマーのホスティング、両方のページビューとパフォーマンス測定
- Upstash — 公式サイトとウェブタイマーの日次集計イベントカウントの保存
- GitHub — ソースコード、リリース情報、GitHub 配布デスクトップ版の更新チェック
- Apple — App Store と StoreKit を通じたアプリ配布、Plus の支払いと購入確認、iPhone または iPad で有効にした場合のプライベート iCloud 同期
- Microsoft — 開いた Microsoft Store リスティングの配布と更新
- サードパーティのダウンロードミラー、GitHub 配布デスクトップ版から選択した場合のみ使用
- カウントダウンを共有するときに選択したサードパーティのソーシャルサービス

## データの削除

ウェブタイマーでは、ブラウザでこのサイトのデータ（ローカルストレージと言語 Cookie を含む）を消去します。Mac または Windows では、アプリをアンインストールしてデータを削除します。

iPhone と iPad では、アンインストールするとその端末に保存されたデータが削除されます。iCloud 同期を有効にしていた場合、プライベート iCloud コピーは他の端末で引き続き利用できます。DoneAt の「記録とデータ」設定で「iCloud から削除」を選択すると、iCloud コピーが削除され、その Apple アカウントにサインインしている端末の関連する同期記録が次回同期時にクリアされます。「この端末からのみ記録を削除」を選択すると、iCloud コピーは復元用に残ります。以前エクスポートしたバックアップファイルは、保存または共有した場所から個別に削除する必要があります。

DoneAt はあなたの Apple アカウントにアクセスしたり、そのプライベート iCloud データをあなたに代わって削除したりすることはできません。DoneAt はサーバーからあなたのローカルデータにアクセスしたり削除したりすることもできません。
