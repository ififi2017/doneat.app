title: "ダウンロード — DoneAt"
description: "App Store または Microsoft Store から DoneAt を入手。iPhone ではウィジェット、ライブアクティビティ、無料の Apple Watch 版、祝日対応の月間シフトカレンダーが使えます。各プラットフォームの動作環境も記載。"
heading: "自分の時間を、いつも手元に。"
intro: "スマートフォンをちらっと見る。手首を上げる。デスクトップの隅に置く。シフトの残り時間を、あなたの使いやすい場所で確認できます。"
nativeHeading: ネイティブアプリを使う理由
nativeLead: ブラウザタイマーでも始められます。スマートフォンやパソコンに入れれば、ページを閉じても DoneAt は動き続けます。
nativePerks:
  - title: 通知が届く
    body: 画面を離れても、シフト終了間際にシステムが知らせてくれます。ブラウザではタブを開いている間だけ可能です。
  - title: いつでも見られる
    body: パソコンではメニューバーやシステムトレイに残り時間を表示。スマートフォンでは他のアプリやウィジェットと並べて置けます。ブラウザのタブを探す必要はありません。
  - title: 閉じてもカウントが続く
    body: ページを閉じたり、スマートフォンをロックしたり、ウィンドウを隠しても、インストールした端末ではカウントダウンが続きます。
nativeNote: Mac と Windows のデータはそのパソコンに保存されます。iPhone と iPad ではデフォルトでローカル保存、オプションでプライベート iCloud データベースを使った同期も可能です。DoneAt アカウントを作る必要はありません。
requirementsHeading: 動作環境
requirements:
  - Windows：Windows 10 20H2 以降（WebView2 が必要）
  - macOS：macOS 13.0 以降
  - iOS/iPad OS：iOS 26.0/iPad OS 26.0 以降
  - Chrome 拡張機能：Chrome 120 以降
chromeExtensionLabel: Chrome ウェブストア
chromeExtensionNote: Chrome 拡張機能版もあります。ツールバーのアイコンをクリックすると残り時間が見られます。
githubReleaseLabel: GitHub Releases
githubReleaseNote: macOS と Windows のインストーラーのみ。未署名です。
