## DoneAt 儲存的資料

你輸入的資訊預設保存在本地：網頁計時用瀏覽器的本機儲存空間，iPhone、iPad、Android、Mac 和 Windows 則用應用程式資料夾。DoneAt 不提供產品帳號，也不會把這些資訊傳送到 DoneAt 的伺服器。

在 iPhone 和 iPad 上，你可以選擇開啟 iCloud 同步。它會把你的排班、記錄、薪資、提醒偏好、外觀、語言、人生檔案和專注資料儲存在你 Apple 帳號下的私人 iCloud 資料庫中。通知授權、生物辨識保護、即時動態設定、當前工作計時器和上手狀態仍留在每台裝置上。網頁計時、Android、Mac 應用程式和 Windows 應用程式保持本地存放，不參與此同步。

倒數計時、進度和收入估算都在你的裝置上根據這些資訊計算。

通常包括：

- 上下班時間、工作日、休息或加班設定
- 薪資金額、薪資週期和職涯薪資歷史
- 工作記錄與更正、職涯階段、你選擇輸入的人生里程碑或日期
- 專注任務標題、計畫、專注時段和休息設定
- 通知和提醒偏好
- 語言和外觀

## 可選的 iCloud 同步

同步預設關閉。當你在 iPhone 或 iPad 上啟用時，Apple 的 CloudKit 服務會將上述資料儲存在與你 Apple 帳號關聯的私人資料庫中。DoneAt 不會在自己的伺服器上收到副本。使用相同 Apple 帳號的裝置可以復原和同步這些資料；這需要可用的 iCloud 帳號和網路連線。

啟用同步需要 DoneAt Plus。已啟用的同步在訂閱到期後仍會繼續。關閉同步會停止該裝置上的同步並保留其當前本地副本和現有 iCloud 副本。關閉同步不會刪除任何一份副本。

## Android

Android 應用程式目前處於測試階段，公開下載與 Plus 購買以 Google Play 發布為準。工作資料與設定預設儲存在應用程式的私有空間，不需要 DoneAt 帳號，應用程式不收集使用統計。

系統備份與裝置移轉可能包含記錄、薪資、職涯歷史、生活檔案、Focus 資料及未完成的初始設定，取決於裝置、帳號及系統設定；DoneAt 伺服器不會收到副本。執行中的計時器、提醒登記與購買憑證不納入系統備份；還原後會重新安排提醒並核對購買。沒有自動 Google Drive 同步，也不與 iPhone 自動同步。手動匯出的備份是可直接讀取的 JSON，可能包含薪資，所選位置或接收人會取得獨立副本。

Google Play 處理購買及自願提交的評分。DoneAt 不會取得信用卡資料，也不會收到是否提交評分的結果。包含商品識別碼與權杖的購買憑證儲存在本機，排除於系統備份。啟動、返回前景、回復購買或重試購買確認時，可能再次查詢。啟用伺服器驗證時，應用程式透過 HTTPS 向 Cloudflare 上的 `api.doneat.app` 傳送權杖、商品識別碼與隨機請求識別碼；Google 透過 Cloud Pub/Sub 通知狀態變更。服務向 Google 核對權益與精確到期時間，回傳簽章憑證，不接收工作資料或備份。

資料庫保存權杖雜湊、商品、權益狀態與期限、驗證時間、測試購買標記、替換權杖雜湊及修訂號，用於驗證、回復及防止已替換的購買再次生效。通知識別碼按 30 天範圍去重，在後續通知處理時清除舊項目。原始權杖與 Google 回應僅暫時處理，不存入資料庫或應用程式日誌。IP 限流是暫時的，DoneAt 資料庫不保存 IP 或其雜湊。Google 與 Cloudflare 依各自政策處理流量。購買識別資料不用於廣告或使用行為分析。

提醒在裝置上安排。裝置驗證只回傳結果，不傳送生物特徵或 PIN。Backdrop（AndroidLiquidGlass）與 Shapes 在本機繪圖，不向作者傳送應用程式內容或裝置識別碼；來源與授權條款見[關於](/zh-TW/about#android)。

本機資料可在應用程式內、清除應用程式儲存空間或解除安裝時刪除。匯出檔案與系統備份需在各自儲存服務另行刪除。若要刪除伺服器購買記錄，請聯絡 [hello@doneat.app](mailto:hello@doneat.app)。刪除本機資料不會自動刪除伺服器記錄或取消訂閱；訂閱請在 Google Play 管理。沒有有效 Plus 仍可匯出及刪除資料。


## 備份匯出

在 iPhone 和 iPad 上，只有在你選擇匯出時才會建立備份匯出。完整備份包括你的記錄、已同步的設定、薪資和職涯薪資歷史、人生檔案、專注任務和專注時段。你也可以選擇不包含人生檔案的匯出；該選項仍包含薪資和職涯歷史。系統分享選單隨後讓你選擇儲存或分享檔案的位置。

匯出是可讀的 JSON 檔案，不是密碼保護的壓縮檔。請選擇適合其所含資訊的儲存位置和接收者。你儲存或分享的檔案是獨立的副本；在 DoneAt 中刪除資料不會刪除這些檔案。

## Plus 購買

在 iPhone 和 iPad 上，Apple 透過 App Store 處理 Plus 訂閱和終身購買。DoneAt 使用 StoreKit 驗證購買狀態和恢復存取權，並在本地保留已驗證權益和任何到期日的記錄。DoneAt 不會收到你的付款卡詳細資訊，也不會將你的購買狀態傳送到 DoneAt 帳號伺服器。Apple 根據其自己的政策處理購買資訊。

訂閱到期不會刪除你現有的記錄。無需有效訂閱即可匯出和刪除。

## 官網

[doneat.app](https://doneat.app) 是靜態網站。它不會收集你的班次或薪資。打開網站根目錄或短路徑如 `/privacy` 或 `/download` 時，會根據你的瀏覽器語言引導你到該語言的首頁或英文／簡體中文支援頁面。語言保留在頁面網址中；本網站不設定語言 Cookie。

為了託管頁面，Vercel 可能會根據其自己的隱私權政策處理 IP 位址和瀏覽器標識等常規連線資訊。本專案不會儲存這些資訊或用它來建立你的個人檔案。

官網使用 Vercel 的無 Cookie 分析來衡量頁面瀏覽量和載入效能，以及少量合計計數器來了解人們使用哪些入口。事件來自固定的公開清單——例如 `hall_view`、`download_view`、`download_from_web`、`web_timer_open` 或 `app_store_open`——並按天遞增。請求只攜帶事件名稱。它不包含使用者標識、工作階段、語言、班次或薪資，無法用於識別或追蹤個人。

完整的事件清單在此儲存庫的 [`src/lib/analytics-events.ts`](https://github.com/ififi2017/doneat.app/blob/main/src/lib/analytics-events.ts)。

## 網頁計時分析

[off.rainif.com](https://off.rainif.com) 的網頁計時也使用 Vercel 的無 Cookie 分析來衡量頁面瀏覽量和載入效能。它使用另一組有限的合計計數器來了解整體功能使用情況。

產品事件來自另一個固定的公開清單，如 `share_open` 或 `countdown_start`，並按天彙總。它們不包含使用者標識、工作階段資訊、班次或薪資資料，無法用於識別或追蹤個人。

完整的產品事件清單可在產品的開源儲存庫中找到。託管和分析供應商可能會根據各自的隱私權政策處理標準連線資訊。本專案不會單獨儲存這些資訊或用它來建立使用者檔案。

## Cookie

網頁計時使用名為 `i18nextLng` 的 Cookie 來儲存語言代碼，以便後續訪問可以用你選擇的語言打開。它在首次訪問時根據當前顯示的語言設定，在你更改語言時更新，一年後過期，可以在瀏覽器中移除。

官網和網頁計時都不使用廣告或跨網站追蹤 Cookie。上述分析不依賴 Cookie。

## 分享倒數計時

分享連結的網址只包含上下班時間。它不包含薪資資訊。打開連結的人只能看到班次時間。倒數計時分享圖片也不包含薪資。備份匯出則不同：它可能包含薪資和上面列出的其他個人資料。

如果你選擇透過第三方社交服務分享，該服務的隱私權政策適用。

## 手機和電腦上的應用程式

iPhone、iPad、Mac 和 Windows 應用程式不收集使用分析。

從 GitHub 安裝的桌面版本在啟動時會檢查是否有新版本。請求不包含帳號、薪資或使用資料，只有在你確認更新後才會下載安裝程式。如果無法直接連線 GitHub，你可以選擇透過第三方鏡像重試。透過任一管道下載的更新在安裝前都會驗證簽章。

從 Microsoft Store 安裝的版本不會主動檢查更新。更新由 Microsoft Store 提供。

提醒由作業系統在本地排程和顯示。應用程式在你打開外部連結或選擇透過第三方服務分享時也會存取網路。

## 小工具、即時動態和裝置保護

小工具和即時動態使用顯示計時器和進度所需的資訊，包括適用時的專注資訊。它們不包含薪資。本地通知也不包含薪資。這些介面可能在你的主畫面或鎖定畫面上可見；你可以在應用程式和系統設定中管理其可見性和通知權限。

當 DoneAt 要求你進行身份驗證以保護收入或記錄時，身份驗證由裝置透過 Face ID、Touch ID 或其密碼處理。DoneAt 只會收到身份驗證結果，而不是你的生物辨識資料或密碼。此保護在每台裝置上單獨設定。

## 第三方服務

DoneAt 使用以下服務來託管頁面、衡量官網和網頁計時、分發應用程式和打開你選擇的連結：

- Vercel — 官網和網頁計時的託管；兩者的頁面瀏覽量和效能衡量
- Upstash — 官網和網頁計時的每日合計事件計數儲存
- GitHub — 原始碼、版本資訊、GitHub 分發桌面版本的更新檢查
- Apple — 透過 App Store 和 StoreKit 進行應用程式分發、Plus 付款和購買驗證，以及當你在 iPhone 或 iPad 上選擇啟用時的私人 iCloud 同步
- Microsoft — 你打開的 Microsoft Store 列表的分發和更新
- 第三方下載鏡像，僅在你從 GitHub 分發的桌面版本選擇時使用
- 你分享倒數計時時選擇的第三方社交服務

## 刪除你的資料

在網頁計時上，在瀏覽器中清除此網站的資料，包括本機儲存空間和語言 Cookie。在 Mac 或 Windows 上，解除安裝應用程式並刪除其資料。

在 iPhone 和 iPad 上，解除安裝會移除儲存在該裝置上的資料。如果你啟用了 iCloud 同步，私人 iCloud 副本仍可供你的其他裝置使用。在 DoneAt 的「記錄與資料」設定中選擇「從 iCloud 刪除」會刪除 iCloud 副本，並在下次同步時清除登入該 Apple 帳號的裝置上相關的已同步記錄。僅從此裝置移除記錄會保留 iCloud 副本以供恢復。你之前匯出的備份檔案必須從你儲存或分享它們的地方單獨刪除。

DoneAt 無法存取你的 Apple 帳號或代表你刪除其私人 iCloud 資料。DoneAt 也無法從伺服器存取或刪除你的本地資料。
