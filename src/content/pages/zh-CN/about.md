## 为什么做这个项目

还剩多久、走了多少、可选的今日已赚，放在同一个安静的界面里，这一天会好过一些。DoneAt 就是那个可以一直开着的小工具。

你可以[从浏览器开始](https://off.rainif.com/zh-CN)，也可以到[下载](/zh-CN/download)页把它留在手机或电脑上。

Off Work Countdown 现为 DoneAt。倒计时还是那个倒计时，门口的名字更短了。

## 什么留在你的设备上

上下班时间、工作日、薪资和偏好都留在你正在用的这台设备上，倒计时和收入估算也在本地算完。iPhone、iPad、Mac 和 Windows 上的应用不会把这些设置或用户标识发到我们的服务器。

官网和网页计时会记录页面访问、加载表现，以及少量合计事件。事件里只有事件名称，没有班次、薪资、账号或广告标识。和其他网站一样，托管与统计服务商仍可能依据其条款收到 IP 地址、浏览器标识等常规连接信息。细节见[隐私](/zh-CN/privacy)。

日常使用不用注册。从 GitHub 安装的桌面版会在启动时向 GitHub 查询是否有新版本；这次请求不含账号、薪资或使用数据，安装包只有你确认更新后才会下载。从 Microsoft Store 安装的版本不自己检查更新。

打开外部链接或社交分享时，会到达对方自己的条款。原生提醒由操作系统在本机调度。卸载应用并删除本地数据，即可清掉设置。

## 重要限制

薪资与时间汇总只供个人参考，不是工资记录，也不构成法律、税务、劳动关系或财务建议。提醒不要用在安全关键或法律要求的计时上。

本软件依据 MIT 许可证按现状提供，在法律允许的范围内不作保证。仓库里的许可证原文是具有约束力的法律声明。
