## 为什么做这个项目

还剩多久、走了多少、可选的今日已赚，放在同一个安静的界面里，这一天会好过一些。DoneAt 就是那个可以一直开着的小工具。

你可以[从浏览器开始](https://off.rainif.com/zh-CN)，也可以到[下载](/zh-CN/download)页把它留在手机或电脑上。

Off Work Countdown 现为 DoneAt。倒计时还是那个倒计时，门口的名字更短了。

## iPhone 和 iPad 上的 3.1.9

除了看清下班时间，DoneAt 也帮助你回顾工作、安排接下来的时间：

- 查看周、月、年记录，轻点时间片段看详情，或双击某一天展开查看。
- 添加人生里程碑与职业阶段，把工作放进生活中回看，了解过去的估算和当前工作阶段。
- 安排任务，用专注计时器交替进行专注与休息。
- 换设备时，通过快速设置恢复已有的 iCloud 记录。

这些功能属于原生 iPhone 和 iPad 应用。各平台的功能介绍见[下载页](/zh-CN/download)。

## 你的数据会去哪里

上下班时间、工作日、薪资和偏好默认留在你正在用的这台设备上，倒计时和收入估算也在本地算完。在 iPhone 和 iPad 上，你可以选择通过私人 iCloud 数据库同步排班、记录、薪资和设置。Mac、Windows 和网页计时仍只保存在本地。各端都不会把这些设置或用户标识发送到 DoneAt 的服务器。

官网和网页计时会记录页面访问、加载表现，以及少量合计事件。事件里只有事件名称，没有班次、薪资、账号或广告标识。和其他网站一样，托管与统计服务商仍可能依据其条款收到 IP 地址、浏览器标识等常规连接信息。细节见[隐私](/zh-CN/privacy)。

日常使用不用注册 DoneAt 账号。从 GitHub 安装的桌面版会在启动时向 GitHub 查询是否有新版本；这次请求不含账号、薪资或使用数据，安装包只有你确认更新后才会下载。从 Microsoft Store 安装的版本不自己检查更新。

打开外部链接或社交分享时，会到达对方自己的条款。原生提醒由操作系统在本机调度。本地与同步数据的删除方式见隐私政策；在 iPhone 和 iPad 上，同步数据可在“记录与数据”设置中另行删除。

## 重要限制

薪资与时间汇总只供个人参考，不是工资记录，也不构成法律、税务、劳动关系或财务建议。提醒不要用在安全关键或法律要求的计时上。

本软件依据 MIT 许可证按现状提供，在法律允许的范围内不作保证。仓库里的许可证原文是具有约束力的法律声明。

## 免费倒计时与可选的 Plus

下班倒计时保持免费。iPhone 和 iPad 上的 DoneAt Plus 提供完整记录、生活视图和专注工具，可通过 App Store 选择月度订阅、年度订阅或终身购买。价格和适用的试用信息会在应用内购买前显示。

首次开启 iCloud 同步需要 Plus。已开启的同步在订阅到期后仍会继续，已有记录也会保留；导出与删除数据不需要有效订阅。
