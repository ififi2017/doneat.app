## 为什么做这个项目

把还剩多久、走了多少、可选的今日已赚放在同一个安静的界面里，这一天会好过一些。DoneAt 就是那个可以一直开着的小工具。

你可以[从浏览器开始](https://off.rainif.com/zh-CN)，也可以到[下载](/zh-CN/download)页把它留在手机或电脑上。

Off Work Countdown 现为 DoneAt。倒计时还是那个倒计时，门口的名字更短了。

## 本地优先与隐私

上下班时间、工作日、薪资和偏好都保存在你的设备上，倒计时与收入估算也完全在本地计算。iPhone、iPad、Mac 和 Windows 上的应用不会把这些设置或用户标识发送到我们的服务器。

网页计时会统计页面访问和加载表现，并记录少量合计事件。事件里只有事件名称，没有你的班次、薪资、账号或广告标识。和其他网站一样，托管与统计服务商仍可能依据其自身条款收到 IP 地址、浏览器标识等常规连接信息。细节见[隐私](/zh-CN/privacy)。

## 应用会访问哪些网络

无需账号，日常使用可以完全在本地完成。

从 GitHub 安装的桌面版本会在启动时向 GitHub 查询是否有新版本，这次请求不包含账号、薪资或使用数据；安装包只有在你确认更新之后才会开始下载。从 Microsoft Store 安装的版本不会自行检查更新——更新由商店负责。

无论哪个版本，打开外部链接或选择社交分享服务时都会访问网络。这些目的地适用各自的条款。

原生提醒由操作系统在本机调度和显示。设置保存在应用的本地数据中；卸载并删除对应数据即可清除。

## 重要限制与法律说明

薪资与时间汇总只是供个人参考的估算，不是工资记录，也不构成法律、税务、劳动关系或财务建议。提醒不应被用于安全关键或法律要求的计时场景。

本软件依据 MIT 许可证按现状提供，在法律允许的范围内不作任何保证。仓库中的许可证原文是具有约束力的法律声明。
