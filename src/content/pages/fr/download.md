nativeLead: Le minuteur navigateur suffit pour commencer. Sur téléphone ou ordinateur, DoneAt continue après la fermeture de la page.
nativePerks:
  - title: Les notifications arrivent
    body: Loin de l'écran, le système peut vous prévenir quand le quart se termine. Dans le navigateur, cela ne fonctionne que si l'onglet reste ouvert.
  - title: Toujours accessible
    body: Sur ordinateur, le temps restant peut rester dans la barre de menus ou la zone de notification. Sur téléphone, il peut côtoyer vos autres apps et widgets. Plus besoin de chercher un onglet.
  - title: Le compte continue
    body: Fermez la page, verrouillez le téléphone ou cachez la fenêtre. Le compte à rebours sur l'appareil installé continue là où vous l'avez laissé.
nativeNote: Les données sur Mac et Windows restent sur cet ordinateur. Sur iPhone et iPad, les données sont locales par défaut, avec synchronisation optionnelle via votre base de données iCloud privée. Pas de compte DoneAt à créer.
