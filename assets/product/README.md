# Homepage product assets

These assets come from the existing DoneAt iOS 3.2.0 marketing source captures in `ififi2017/Off-Work-Countdown/scripts/marketing-shots/ios`. The product repository was read only.

The Island, Live Activity and Home Screen widget images are exact rectangular crops of `raw/en-2.png` and `raw/zh-2.png`, using the already verified `widget-crops.json` bounds. The crops are stored as lossless WebP. The Watch captures and the Apple frame are copied unchanged. `sources.json` records each source, SHA-256 and crop rectangle. The Apple frame's supplied license is retained here.

No product interface was generated, redrawn or translated. Product labels inside the captures remain in English or simplified Chinese; the website's surrounding captions are localized. Marketing headlines are native website text, rather than text embedded in an App Store poster.
