# doneat.app

Official website for **[DoneAt](https://doneat.app)** — Know when your time is yours.

This repository is the marketing and support site. It is not the countdown app.

| Surface | Where |
| --- | --- |
| Official site | [doneat.app](https://doneat.app) (this repo) |
| Web app | [off.rainif.com](https://off.rainif.com) |
| Product source (Web, Desktop, iOS) | [ififi2017/Off-Work-Countdown](https://github.com/ififi2017/Off-Work-Countdown) |

Stack: Astro, TypeScript, Tailwind CSS. Hosted on Vercel.

Clone into a folder that does **not** end in `.app` (for example `doneat-site`). macOS treats `*.app` as an application bundle, which hides the files in Finder and can block Cursor from opening the project. The GitHub repo name stays `doneat.app`.

Development plan: [PLAN.md](PLAN.md) (Chinese). Coordinated go-live with the product repo is in [Off-Work-Countdown 009](https://github.com/ififi2017/Off-Work-Countdown/blob/main/plans/009-doneat-platform-brand-domain.md).
